# 料理伝言ゲーム

高専祭の学科展示用ゲームです。
PC1 の人（**おくる人**）が料理の情報（食材3つ・調味料・調理方法・一言メモ）を送り、PC2 の人（**あてる人**）がその情報から料理を当てます。2人で協力して遊びます。

- PC は2台。ルーターの LAN でつなぎます（**インターネットは不要**）。
- サーバーは PC1 で動かします。

| PC | 役割 | 開くページ |
| --- | --- | --- |
| PC1 | おくる人（送信側）＋サーバー | `http://localhost:3000/sender.html`（start.bat で自動で開く） |
| PC2 | あてる人（受信側） | `http://<PC1のIPアドレス>:3000/receiver.html` |

---

## 1. 初回セットアップ（準備の日に1回だけ）

インターネットにつながる PC で作業します。

### 1-1. Node.js を入れる（PC1 だけ）

1. https://nodejs.org/ から **LTS 版**の Windows インストーラー（`.msi`）をダウンロードします。
   - 本番の PC1 がインターネットにつながらない場合は、この `.msi` を USB メモリで持っていきます。
2. インストーラーを実行し、すべて「次へ」で進めます。
3. 確認：コマンドプロンプトで `node -v` と入力し、`v20.x.x` などのバージョンが出れば OK です。

> PC2 には Node.js は不要です。ブラウザ（Edge か Chrome）だけあれば動きます。

### 1-2. 必要なライブラリを入れる

このフォルダでコマンドプロンプトを開き、次を実行します。

```
npm install
```

`node_modules` フォルダができれば OK です。
**このフォルダごと（`node_modules` も含めて）PC1 にコピー**すれば、当日はインターネット無しで動きます。

### 1-3. 動作チェック（任意）

```
npm test              … 採点などのテスト
npm run check-dishes  … 料理データのチェック（同じ組み合わせの料理が無いか）
npm run check-assets  … まだ画像が無い食材・料理などの一覧
```

1台だけでの確認：`start.bat` を実行し、同じ PC のブラウザで `http://localhost:3000/receiver.html` も開けば、2つのウィンドウで遊べます。

## 2. 当日の手順

1. **ルーターの電源を入れる**（ランプが落ち着くまで1〜2分待つ）
2. **2台の PC をルーターにつなぐ**（LAN ケーブル推奨。Wi-Fi の場合は2台とも同じ SSID に）
3. **ネットワークを「プライベート」にする**（PC1・PC2 とも。初めて使うルーターでは必須）
   - 設定 → ネットワークとインターネット → イーサネット（または Wi-Fi）→ つながっているネットワーク → **ネットワーク プロファイルの種類：プライベート**
4. **PC1 で `start.bat` をダブルクリック**
   - 黒い画面に **PC1 の IP アドレス**と **PC2 で開く URL** が大きく表示されます。
   - この黒い画面は**閉じないでください**（閉じるとゲームが止まります）。
   - 送信側の画面が自動で開きます。
5. **ファイアウォールを許可する**（初回だけ）
   - 初めて起動したとき「Windows セキュリティの重要な警告」が出たら、**「プライベート ネットワーク」にチェック**を入れて「アクセスを許可する」を押します。
   - 出なかった／間違えて拒否した場合は「7. つながらない時」の ③ を見てください。
6. **PC2 のブラウザで URL を開く**
   - 黒い画面に出ている `http://192.168.x.x:3000/receiver.html` を入力します。
   - 右上に「おくる人：OK」と緑で出れば接続成功です。
7. **両方のブラウザで F11 を押してフルスクリーンにする**
8. **両方の画面を1回クリックする**
   - ブラウザの仕様で、一度クリックするまで音が出ません。特に PC2 は忘れずに。

### 片付け

- 黒い画面で `Ctrl + C` を押すか、黒い画面を閉じるとサーバーが止まります。

## 3. スタッフ向けの操作

| こんなとき | 操作 |
| --- | --- |
| 画面がおかしい・途中でやめたい | どちらかの PC で **Ctrl + Shift + R**（両方がタイトルに戻る） |
| 片方の画面が「接続中…」のまま | 「7. つながらない時」へ |
| ブラウザを閉じてしまった | もう一度 URL を開けば、続きの画面に戻ります |
| 「ほかの画面でひらかれました」と出た | 同じ役割の画面が2つ開いています。使う方の画面で F5 |

自動で行われること：

- 遊んでいる途中で **90秒**操作が無いと「まだあそんでるかな？」のカウントダウンが出て、その後タイトルに戻ります。
- リザルト画面は **20秒**で自動的にタイトルに戻ります。
- **きょうのきろく**（あそんだ回数・正解数・100%達成回数）がタイトル画面に出ます。記録は `data/records.json` に日付ごとに保存され、日付が変わると 0 から数え直します。記録を消したいときはサーバーを止めてから `data/records.json` を削除します。

## 4. 設定（`config.json`）

| 項目 | 意味 | 初期値 |
| --- | --- | --- |
| `port` | ポート番号（変えたら PC2 の URL も変わる） | `3000` |
| `difficulty` | `"easy"`：全部見せる / `"hard"`：一言メモ以外から1つを「？」で隠す | `"easy"` |
| `sound` | 効果音 `true` / `false` | `true` |
| `idleTimeoutSec` | 放置でタイトルに戻るまでの秒数（`0` で無効） | `90` |
| `resultReturnSec` | リザルトからタイトルに戻るまでの秒数 | `20` |
| `choices` | 受信側が選ぶ料理の数。`easy` / `hard` ごとに書く（`0` = 全部の料理から選ぶ） | `{"easy": 4, "hard": 0}` |

`port` 以外は、保存すると次のラウンドから反映されます（`port` はサーバーの再起動が必要）。
一時的に別のポートで動かしたいときは、`config.json` を変えずに環境変数でも指定できます（例：コマンドプロンプトで `set PORT=3001` のあと `node server\index.js`）。
画面の表示（効果音の ON/OFF など）は、ブラウザで F5 を押すと反映されます。

## 5. 画像・効果音の差し替え

ファイルを置いて**ブラウザで F5** を押すだけで切り替わります。無いものは絵文字・合成音で代わりに表示・再生されます。

| 種類 | 置き場所 | 形式 |
| --- | --- | --- |
| 食材 | `public/assets/ingredients/<食材ID>.png` | 512×512、背景透過 PNG |
| 調味料 | `public/assets/seasonings/<調味料ID>.png` | 同上 |
| 料理 | `public/assets/dishes/<料理ID>.png` | 同上 |
| 道具 | `public/assets/tools/<調理方法ID>.png` | 同上 |
| なぞの料理 | `public/assets/dishes/mystery.png` | 同上（無ければ作れた料理を変な色で表示） |
| キャラクター | `public/assets/chara/<sender か receiver>/<ポーズ>.png` | 背景透過 PNG（縦長） |
| 背景 | `public/assets/bg/<sender / receiver / cooking>.jpg` | 1920×1080 |
| おなべ（食材の画面） | `public/assets/ui/pot.png` | 横幅 900px まで・背景透過（無ければCSSで描いた鍋） |
| 効果音 | `public/assets/sounds/<名前>.mp3`（`.wav` `.ogg` も可） | — |

ID は `data/` の JSON を見てください（例：`meat.png`、`curry.png`、`simmer.png`）。

### アニメ風イラストの作り方

1. `docs/ART_PROMPTS.md` のプロンプトを Gemini（Nano Banana）に入れて画像を作り、`art-raw/<種類>/<ファイル名>.png` に保存します（背景はマゼンタ）。
2. `python scripts/process-art.py` を実行すると、マゼンタを透明にして大きさをそろえ、`public/assets/` に置きます（初回だけ `python -m pip install pillow numpy`）。

キャラクターの画像が1枚も無いときは、キャラは出ません（今までどおりの画面で動きます）。

まだ画像が無いもの（絵文字で表示しているもの）は、次のコマンドで一覧にできます。

```
npm run check-assets
```

効果音の名前：

| 名前 | 鳴るところ |
| --- | --- |
| `button` | ボタンを押したとき・完成度のカウントアップ |
| `select` | 選択カードを押したとき |
| `send` | 情報を送る／受け取るとき |
| `drop` | 食材が道具に落ちるとき |
| `cooking` | 調理中（ジュージュー） |
| `complete` | 料理ができた「ジャーン！」 |
| `correct` / `wrong` | 正解 / ざんねん |
| `fanfare` | 完成度100%（大成功） |
| `funny` | なぞの料理（ずっこけ） |

## 6. 料理・語群を増やす／直す

コードを変える必要はありません。

1. `data/dishes.json` に料理を追加（`id` は英数字、食材は3つ、調味料と調理方法は `data/` にある ID）
2. 名前に新しい漢字があれば `data/furigana.json` に読み方を追加（例：`"焼": "{焼|や}"`）
3. `npm run check-dishes` で、ほかの料理と区別できるか確認
4. 画像を置く場合は `public/assets/dishes/<id>.png`
5. サーバーを再起動して、ブラウザで F5

一言メモの語群は `data/memo_words.json` です。

## 7. つながらない時のチェックリスト

上から順に確認してください。

**① PC1 で `http://localhost:3000/sender.html` は開ける？**
- 開けない → 黒い画面（サーバー）が動いているか確認。`start.bat` をもう一度実行。
- 「ポート 3000 はすでに使われています」と出たら、サーバーが二重に起動しているか、ほかのアプリ（別のゲームのサーバーなど）が 3000 番を使っています。黒い画面をすべて閉じてから `start.bat` を1回だけ実行。それでもだめなら `config.json` の `port` を `3001` などに変えて起動し、PC2 の URL もその番号にする。

**② PC2 から PC1 が見える？（ping）**
- PC2 でコマンドプロンプトを開き `ping 192.168.x.x`（PC1 の IP）
- 「応答」が返る → ③へ
- 「要求がタイムアウトしました」→ ケーブル・ルーター・同じネットワークか（Wi-Fi のゲストネットワークは端末どうしがつながらないことがある）を確認。ネットワークが「プライベート」になっているかも確認。

**③ ファイアウォールでポートが閉じていない？**
- PC1 で **PowerShell を管理者として実行**し、次を入力：
  ```
  New-NetFirewallRule -DisplayName "Ryouri Dengon Game" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
  ```
- または「Windows セキュリティ → ファイアウォールとネットワーク保護 → ファイアウォールによるアプリケーションの許可」で **Node.js JavaScript Runtime** の「プライベート」にチェック。

**④ IP アドレスが変わっていない？**
- ルーターを再起動すると PC1 の IP が変わることがあります。`start.bat` の黒い画面に出ている最新の URL を PC2 で開き直してください。
- コマンドプロンプトで `ipconfig` でも確認できます（「IPv4 アドレス」）。
- 毎回同じにしたい場合は、ルーターの設定で PC1 に固定 IP を割り当てる（DHCP 予約）と安心です。

**⑤ IP アドレスがいくつも出る？**
- `192.168.56.x`（VirtualBox）や `172.x.x.x`（WSL・Hyper-V）は仮想ネットワークなので使いません。黒い画面ではこれらを「使わない仮想ネットワーク」として分けて表示しています。
- ルーターにつながっている方（ふつうは `192.168.x.x`）を使ってください。

**⑥ ルーターが壊れた・無いとき：LAN ケーブルで2台を直結する**
1. LAN ケーブルで PC1 と PC2 を直接つなぐ（最近の PC はふつうの LAN ケーブルで OK）。
2. 両方の PC で IP アドレスを手動で設定する：
   - 設定 → ネットワークとインターネット → イーサネット → IP 割り当て → 編集 → **手動** → IPv4 オン
   - PC1：IP アドレス `192.168.10.1`、サブネットマスク `255.255.255.0`（ゲートウェイ・DNS は空欄）
   - PC2：IP アドレス `192.168.10.2`、サブネットマスク `255.255.255.0`
3. ネットワークを「プライベート」に設定（手順 2-3）。
4. PC2 で `http://192.168.10.1:3000/receiver.html` を開く。
5. 終わったら IP 割り当てを「自動（DHCP）」に戻すのを忘れずに。

**⑦ 音が出ない**
- 画面を1回クリックしたか確認（ブラウザは操作するまで音を出しません）。
- `config.json` の `sound` が `true` か確認。
- PC の音量・ミュートを確認。

## 8. フォルダ構成

```
server/         サーバー（index.js）、ゲーム状態（game.js）、採点（scoring.js）、記録（records.js）
data/           料理・食材などの JSON、ふりがな辞書、記録（records.json）
public/         ブラウザで動く部分
  sender.html     送信側（PC1）
  receiver.html   受信側（PC2）
  css/            見た目
  js/game/        画面遷移・選択ルール・通信
  js/ui/          アニメーション・効果音・ふりがな など
  assets/         画像・効果音（ingredients, dishes, tools, sounds）
tests/          テスト（npm test）
scripts/        check-dishes など
config.json     設定
start.bat       起動用（PC1 でダブルクリック）
```
